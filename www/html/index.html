Hello, We're the Developers

Project Overview

This project is a deep dive into building a fully functional webserver using C++98. Our server handles multiple simultaneous client connections using non-blocking sockets and the epoll system call, ensuring high scalability and efficient use of resources. It also implements a complete HTTP/1.1 request-response cycle, providing a hands-on understanding of both network programming and protocol design.

Non-Blocking Architecture

We designed a non-blocking server that handles multiple requests in parallel, ensuring efficient resource use and responsiveness even under high load.

epoll for Scalable I/O

By using epoll, we minimized the overhead of managing connections, enabling scalable event-driven processing with minimal CPU usage.

HTTP/1.1 Protocol Parsing

We implemented a deep understanding of HTTP/1.1 — from request-line parsing to header extraction, ensuring the server adheres to the protocol specification for both requests and responses.

C++98 — Back to Basics

Sticking to C++98 taught us to manage resources manually and write robust, low-level code that interacts tightly with the OS network stack.
